# 课间 Kejian

面向非全日制 MEM 同学的班级课程助手，支持个人课表、课程作业、个人作业、作业讨论，以及个人 AI 助手接入。手机与电脑共用一套网页界面。

这个公开仓库用于查看源码、本地试用和提交改进。它包含应用代码和**完全虚构的演示数据**，真实同学名单、个人课表、数据库、连接凭据和服务器配置均不随源码提供。本地运行使用独立数据库。

## 可以做什么

- 查看今天课程、完整七天周课表、到校安排和课程详情；显示老师、教室与准确时段。
- 导入课程，逐门核对差异，补充已有课表；从班级课程列表添加课程，或移出自己的课表并撤销。
- 记录个人作业；管理员和指定课代表发布、修改、撤回所属教学班的课程作业。
- 同教学班共享作业要求，个人完成状态分别保存；在课程作业下评论、回复和讨论。
- 作业的具体要求和提交方式分开展示；提交方式可填写网址、线下地点或其他渠道。
- 连接 WorkBuddy 等 AI 助手：提供 HTTP API、Python CLI、可选 MCP 和 Skill，支持按本人权限代办与连接资料自动同步。
- 添加到手机主屏幕。消息提醒当前仅支持 iOS（iPhone / iPad）：添加到主屏幕后，从桌面打开课间，在“更多 → 消息提醒”中主动开启；可接收课前、新课程作业和截止提醒。
- 提醒按本人课表、教学班及个人完成状态筛选，切换账号或退出时解除旧会话的设备接收。AI 定时任务仍由对应 AI 宿主实际创建和执行。

## 教学班必须分清

**行政班相同、课程名相同、老师相同，都不代表同一个教学班。** 同一行政班可以拆成多个教学班，上课时段、作业和课代表各自独立。

课程关联以学校、学期和**完整教学班编号**为依据。课程名称和老师用于展示与核对；不能用它们合并教学班。缺少教学班编号的导入课程先留在个人课表，补齐编号前不自动关联公共作业。

## 本地启动

需要 Python 3.11 或更新版本。演示服务及基础测试只使用 Python 标准库；Node.js 22 或更新版本用于运行前端测试。真实 Web Push 发送是可选服务，需要另外配置私密密钥和独立 worker；演示不会向任何设备发送通知。

```sh
git clone https://github.com/YouHa-UHA/kejian.git
cd kejian
python3 -m classroom.demo
```

打开 <http://127.0.0.1:4188/>。第一次运行会创建 `state/demo.sqlite3`；再次启动保留已有演示进度。

演示账号密码统一为 **`DemoOnly2026!`**，仅用于本地虚构数据库：

| 账号 | 角色 | 场景 |
| --- | --- | --- |
| 2026000001 | 演示管理员 | 管理教学班、设置课代表 |
| 2026000002 | 演示同学甲 | 系统工程 A 班、个人作业 |
| 2026000003 | 演示课代表 | 管理系统工程 A 班课程作业 |
| 2026000004 | 演示空课表 | 首次导入、添加课程 |
| 2026000005 | 演示同学乙 | 同名同老师的系统工程 B 班，用于验证隔离 |

系统工程 A/B 班的老师相同，但教学班编号和时间不同。所有演示姓名、账号、教室和作业均为虚构。演示学期为 2026–2027 秋冬，可切换到对应教学周查看；今日不在学期内时，首页可能没有后续课程。

端口占用时可用 `python3 -m classroom.demo --port 4189`。需要全新演示数据时，改用 `--db state/another-demo.sqlite3`。

## 验证

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
python3 scripts/check_public_source.py
```

测试使用临时数据库，不访问正式服务。测试覆盖教学班隔离、个人权限、课代表范围、导入冲突、移除恢复、作业评论、AI 连接和同步，以及时区、日历与截止时间。

## 源码范围

本次源码以正式版 `20261025-ios-label-r24` 为基准整理，包含已上线的消息提醒、按变更调度、最多 5 个并发发送、更新介绍和独立的作业提交方式。保留正式版网页资源；未合入弃用的界面实验或暂停中的 Android 测试包。

公开版本沿用旧个人版匿名入口的清理，仅保留班级版静态资源适配；演示启动器与测试使用虚构资料。服务器私密配置、数据库、真实账号、密钥与发布备份均不在源码内。拉取源码不会连接或更新正式服务器。
