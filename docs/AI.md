# 连接自己的 AI

网页的“连接 AI”生成个人连接资料。将资料和引导提示交给 WorkBuddy 等助手，由它读取 Skill、核对身份，并通过接口查询或代办。生成 ZIP 本身不表示已经成功连入。

默认可以使用 HTTP API 和包内的 Python CLI，无需为此安装额外 Python 库。支持 MCP 的宿主也可以配置可选 MCP；宿主不支持或没有注册成功时，Skill 会引导改用 API/CLI。

- HTTP API：`/api/agent/v1/`。
- MCP：`/api/mcp`，Streamable HTTP。
- Skill 源文件：`classroom/skills/kejian/SKILL.md`。
- 客户端：`classroom/agent_client.py`，实际资料包由服务器按本人连接生成。

每个任务和定时执行开始时，客户端先核对在线指南、版本与当前权限；有变化则同步，无变化时保持安静。管理员撤销身份或用户删除连接后，旧连接不会继续享有原权限。

课程导入使用“我的课程”的备注和完整教学班编号，不使用有误的网格推断日期。图片里的作业要求应先转为可核对的文字，保留提交格式、范围和时间；不清楚的内容向用户确认。获取作业时应读取完整要求，再给针对内容的学习建议。

AI 定时提醒需要宿主确实支持并创建任务，不能仅复制一段提示词后就宣称已安排。班级网页的自动刷新与手机系统通知分别实现。

连接资料含个人凭据，保存在自己的私密目录，不提交到仓库或公开 Issue。示例与测试只使用临时生成的虚构连接。
